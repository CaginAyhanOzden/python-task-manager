# Python Task Manager

A file-based task management application developed with Python as part of the Arch of Sigma / TNC Group Information Technologies Professional Development Program.

[Open in Google Colab](https://colab.research.google.com/github/CaginAyhanOzden/python-task-manager/blob/main/task_manager.ipynb)

## About the Project

This project is a command-line task management application that allows users to create, view, update and delete tasks.

Task data is stored in a local file so that the saved tasks remain available after the application is closed and restarted.

## Features

- Add new tasks
- List existing tasks
- Edit saved tasks
- Delete tasks
- Store task data in a local file
- Display a simple command-line menu
- Handle user input

## Technologies and Concepts

- Python
- File handling
- Functions
- Lists and dictionaries
- Conditional statements
- Loops
- User input
- Basic error handling

## How to Run

### Run with Python

1. Download or clone this repository.
2. Make sure Python 3 is installed.
3. Open a terminal in the project directory.
4. Run the following command:

```bash
python task_manager.py
```

### Run with Google Colab

Open the `task_manager.ipynb` file or use the Google Colab link at the top of this page.
